### Onigiri Engine
Простенький проект игрового движка, который я пишу для себя в свободное время. Пока что он находится в очень раннем этапе разработки. Конкретно сейчас разрабатывается интерфейс редактора, через который будет осуществлятся основная разработка игры.
### Сборка
Для сборки этого проекта ничего не нужно. В репозиторий уже встроен компактный premake программа с заранее созданным скриптом для сборки проетка под Visual Studio 2022.
